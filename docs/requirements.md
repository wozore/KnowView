# 知览（KnowView）需求规格

> 当前 MVP 的功能、非功能需求、范围和验收状态。未来长期演进见维护者工作稿开发计划。

## 需求依据

需求来自问题定义、N=112 用户调查（原始材料见 resources/survey/）、前期问答和技术 PoC。调查以学生样本为主且存在若干统计口径矛盾，百分比只能作为样本内证据，不代表普遍市场结论。

| 痛点 | 衍生能力 |
|---|---|
| 信息分散、更新快 | 工具聚合、时效标注和更新机制 |
| 软文多、宣传与实际不符 | 公开证据和可信评测 |
| 工具与任务难匹配 | 场景导航和推荐 |
| 选择困难、容易选错 | 多维度对比 |
| 价格和权益不透明 | 套餐、额度和价格展示 |

## MVP 范围

**包含：** 工具聚合、场景化发现、多维比较、价格与权益透明化、人工推荐、热点聚合、概念词典和 RSS。

**不包含：** 用户账户/UGC 社区、数据库或运行时 Serverless 采集、实时推送、AI 自动事实裁决、工具代理销售、自有模型训练、企业部署咨询和高频 LLM/Agent API 调用。
