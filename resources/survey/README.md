# 调查原始材料

> 本目录保存早期用户调查（原 user-survey-full 分析报告）的原始数据与可复现分析材料。所有已脱敏，不含受访者个人可识别信息。

## 文件清单

| 文件 | 用途 |
|---|---|
| `questionnaire.pdf` | 实际执行的 22 题问卷原文 |
| `survey-data-coded.csv` | 编码后数据，N=112，每个选项独立成列（选中=1，未选=空） |
| `analysis.py` | Python 分析脚本，输出逐题统计、交叉分析和勘误校准 |

## 编码规则

- 性别：缺失 25 例（22.5%），按已知男女比 45:42 比例插补（13男:12女），补全后男 58、女 54；原报告使用行序确定性补全（前17男后8女→男62女50），两种方法相差约4人，脚本默认使用比例法
- 单选题：按选项编码为数字（1 起）
- 多选题：每选项独立列，选中为 `1`、空字符串为未选
- Q18（困扰量表）：1—5 分，数字直接存储

## 勘误说明（已修正）

原报告存在以下统计口径问题，`analysis.py` 已逐一修正。运行脚本输出的校准值为当前正确口径：

| 问题 | 原报告错误 | 修正后 |
|---|---|---|
| 性别比例 | 行序法补全(17男:8女)得男62/女50，且百分比 55.9% 疑以 N=111 计算 | 比例法补全: 男58=51.8%, 女54=48.2% |
| Q7 朋友推荐 | 69/112=62.2%（69/111=62.2%，疑用 N=111） | 69/112=61.6% |
| Q15 匹配困难 | 67.2%，且编码注释误写 E=5（Q15 仅 A-D 四选项） | B+C=67.0%（与报告接近）；B+C+D=72.3%；口径以 B+C 为准 |
| Q16 限选违规 | 未检验限选4项约束，全样本百分比被25名违规者虚高 4-12pp | 全样本前3: 84.8%/76.8%/51.8%；合规样本(N=87)前3: 80.5%/71.3%/40.2% |
| Q18 看不懂介绍 | 2.79（一处笔误） | 2.78 |
| Q20 影响程度 | 29.7%/57.7%/12.6%（中/后两项 64/111=57.7%, 14/111=12.6% 疑用 N=111） | 30.4%/57.1%/12.5%（N=112） |

## 复现步骤

输出包括：勘误校准、逐题统计（含 Q16 全样本/合规样本双口径）、Q18 均值/中位数/SD、交叉分析表。
